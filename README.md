# 共通の開発入口

`fululastock-siz` アカウントのIssue・PR・貢献ガイドラインを置くリポジトリです。AIやPCを交代しても、GitHub上の記録から作業を再開できるようにします。

- コード変更前にIssueへ計画を記録します。
- 作業ブランチで変更し、小刻みにcommitしてPRを作ります。
- 中断前に現在地と次の手順を残します。

文書テンプレート、役割分担、既存リポジトリへの導入手順は [development-standard](https://github.com/fululastock-siz/development-standard) にあります。

GitHubの共通テンプレートは、対象リポジトリに同種の独自テンプレートがない場合に使われます。特に対象側の `.github/ISSUE_TEMPLATE` に有効なテンプレートや設定がある場合、ここにあるIssueテンプレート一式は適用されません。各リポジトリ固有の `AGENTS.md` なども自動コピーされません。固有ルールを確認し、必要な場合だけ個別に統合してください。

このリポジトリは共通テンプレートを配るため公開しています。個別案件の情報や機密事項は置かないでください。
